GLB Viewer

Viewer minimal untuk file .glb / .gltf yang ditulis murni dalam bahasa C dengan rendering PBR (Physically Based Rendering) berbasis OpenGL dan sistem Image-Based Lighting (IBL) lengkap.

C11 OpenGL 3.3 / 4.1 PBR Cook-Torrance IBL Split-Sum CMake 3.16+ glTF 2.0 HDR Environment
📄 Tentang Proyek

GLB Viewer adalah aplikasi desktop ringan yang memungkinkan pengguna memuat dan menampilkan model 3D dalam format .glb (binary glTF) maupun .gltf dengan dukungan gambar eksternal. Seluruh kode ditulis dalam C standar (C11) tanpa ketergantungan pada runtime yang berat.

Renderer mengimplementasikan model pencahayaan Cook-Torrance dengan distribusi GGX, fungsi geometri Smith-Schlick, dan fresnel Schlick, ditambah pencahayaan ambient berbasis Image-Based Lighting (IBL) menggunakan pendekatan split-sum ala Brian Karis (Epic Games).

ℹ️

Proyek tidak memiliki dependensi eksternal yang perlu diinstal secara manual. Semua library (GLFW, cglm, cgltf, stb_image) diunduh secara otomatis oleh CMake pada saat konfigurasi build.

🧱 Modul

gl_loader — Custom OpenGL Function Loader

Menggantikan GLAD/GLEW. File gl_loader.h mendefinisikan semua tipe dasar GL, konstanta (mis. GL_FRAMEBUFFER, GL_RGBA16F), dan pointer fungsi via makro GL_FUNCTIONS(X). Fungsi gl_load() menerima callback get_proc (dari glfwGetProcAddress) dan mengisi semua pointer di runtime.

gltf_model — Parser & Uploader Model

Menggunakan cgltf untuk mem-parse file. Setiap node dalam scene di-traverse secara rekursif; transformasi dunia dihitung dengan mengalikan matriks lokal node terhadap matriks parent. Setiap primitive dikonversi ke GPU object (VAO + VBO + EBO). Vertex dibake langsung ke world space sehingga model matrix di shader selalu identity. Bounding sphere dihitung dari bounding box untuk keperluan auto-fit kamera.

pbr_ibl — Image-Based Lighting Pipeline

Modul terbesar proyek. Membangun 5 shader bake (GLSL 330): konversi equirect, irradiance diffuse, prefilter specular, BRDF LUT, dan background. Menggunakan satu FBO bersama untuk semua pass bake. Mendukung dua format render target: RGBA16F (HDR, ideal) dengan fallback RGBA8 (LDR, untuk driver lawas).

shader — Kompilasi Program GLSL

Wrapper tipis di atas glCreateShader / glLinkProgram. Fungsi shader_build() menerima source vertex dan fragment, mengompilasi, melakukan linking, dan mengembalikan GLuint program siap pakai (atau 0 jika gagal, disertai log error ke stderr).

main — Entry Point & Render Loop

Menginisialisasi GLFW (mencoba GL 4.1, fallback ke 3.3), memuat IBL, membangun shader PBR, memuat model, menyiapkan semua uniform, lalu menjalankan render loop dua pass (opaque → transparent).

💡 IBL Pipeline

Seluruh bake IBL dilakukan saat startup menggunakan satu framebuffer object (FBO) bersama. Pipeline terdiri dari 5 tahap berurutan:

1. Equirect HDR → Texture 2D
Upload float RGBA ke GPU
2. Texture 2D → Env Cubemap 512×512
Render 6 face, generate mipmap
3. Env Cubemap → Irradiance 32×32
Cosine-weighted hemisphere, 1024 sample Hammersley
4. Env Cubemap → Prefilter 256→16 (5 mip)
Importance sampling GGX per roughness, 256 sample
5. BRDF LUT 512×512
Integrasi split-sum Karis, output (A,B) di kanal RG, 512 sample

Resolusi Konstanta

Cpbr_ibl.c
#define ENV_SIZE  512   /* resolusi base env cubemap */
#define IRR_SIZE   32   /* irradiance diffuse */
#define PREF_SIZE 256   /* prefilter specular base */
#define PREF_MIPS   5   /* 256, 128, 64, 32, 16 */
#define LUT_SIZE  512   /* BRDF integration LUT */
⚠️

Driver GPU lama mungkin tidak mendukung float render target (RGBA16F). Dalam kasus ini, bake diulang otomatis dengan format RGBA8 (LDR). Kualitas IBL sedikit berkurang tetapi tetap berfungsi.

🔁 Render Loop

Render loop berjalan hingga window ditutup atau tombol Esc ditekan. Setiap frame mengeksekusi urutan berikut:

  1. Hitung posisi kamera & matriks

    Posisi eye dihitung dari koordinat bola (yaw, pitch, distance). Matriks view (glm_lookat) dan projection (glm_perspective) dibuat. Near plane = radius × 0.01, far plane = radius × 100.

  2. Gambar Background Environment

    Jika IBL tersedia, panggil ibl_draw_background() dengan fullscreen triangle. Depth test dimatikan sementara agar latar selalu muncul di belakang model.

  3. Pass 0 — Opaque & MASK

    Iterasi semua mesh. Mesh dengan alpha_mode == BLEND dilewati. Material uniform di-set, tekstur diikat ke slot 0–4, lalu glDrawElements dipanggil.

  4. Pass 1 — Transparan (BLEND)

    Aktifkan blending (GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA) dan matikan depth write (glDepthMask(GL_FALSE)). Render hanya mesh BLEND. Kembalikan state GL ke semula setelah pass selesai.

  5. Swap Buffer & Poll Events

    glfwSwapBuffers menampilkan frame ke layar; glfwPollEvents memproses input mouse dan keyboard.

ℹ️

Two-pass rendering memastikan objek transparan dirender setelah semua objek opaque selesai, sehingga alpha blending terhadap depth buffer berjalan benar.

Detail Kamera Orbit

Sensitivitas rotasi: 0.01 radian per pixel. Pitch dibatasi antara −1.5 dan +1.5 radian (~86°) untuk mencegah gimbal lock di kutub. Zoom menggunakan faktor eksponensial distance × 0.9^scroll dengan batas 0.05 hingga 5000 unit.

Saat model dimuat, kamera otomatis diposisikan pada jarak radius × 2.5 (minimum 0.5) dan menatap pusat bounding sphere model.
